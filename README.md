# Seven Seconds — the Amen break

No-build static scrollytelling site (index.html, style.css, engine.js, wheel.js, app.js, tracks.js).
Preview: launch config `amen-break` (port 4340) in `BF Workspace/.claude/launch.json`.

- **engine.js** — the break (4 bars, 64 sixteenth steps, after Ethan Hein's transcription), a synthesized drum kit
  rendered once with OfflineAudioContext and played at `playbackRate = bpm/136` (tempo and pitch move together,
  like a sped-up record), a lookahead scheduler, and 30-second previews through the Apple iTunes Search API.
  Nothing here is the 1969 recording.
- **wheel.js** — the canvas record: lanes are crash, ride, snare (+ghosts), kick. Tap/drag to audition a slice.
- **app.js** — scroll scenes, chop lab (16 slots x 16 beat-slices, share link `#chop=<hex16>&bpm=n`), radial "echoes" chart.
- **tracks.js** — generated by `data-prep/build_tracks.py` (MusicBrainz "samples material" relations of the 1969 recording, CC0,
  plus tracks whose Wikipedia articles name the Amen break), then `data-prep/patch_tracks.py` (drops wrong preview matches,
  adds hand-verified ones). Only tracks with a working 30-second Apple preview are kept (33). Re-run takes ~6 minutes (iTunes rate limit).

Notes: genre families are an editorial grouping by artist. Two undated MusicBrainz tracks and alternate versions are dropped.
